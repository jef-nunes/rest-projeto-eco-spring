## Resumo 🌳📊
Projeto de backend para um site com a temática "desastres naturais e meio ambiente". A aplicação se baseia no padrão arquitetural REST e foi desenvolvida com a linguagem Java e o framework Spring Boot. Destaques do que já foi desenvolvido até agora:
- Integração a banco de dados MySQL
- Endpoints REST 
- Operações CRUD das entidades
- Operações de relacionamentos entre entidades
- Gerenciador de exceções global
- Respostas JSON padronizadas

## Respostas da API
As respostas da API foram padronizadas conforme o exemplo abaixo:

```json
{
  "status":"success",
  "data":[],
  "messages":[],
  "timestamp":"16-09-2025 14:50"
}
```
